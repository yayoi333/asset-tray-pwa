# 素材ポイっと 送信機 (PWA)

スマホで拾ったプロンプトを、出典URL付きでGoogle Driveに送るPWA。
PC側のChrome拡張「素材ポイっと」の受信箱に届きます。

## 使い方

### Xの共有メニューから(Android)
1. Xでプロンプト本文を長押しコピー
2. 同じ投稿の共有ボタン →「素材ポイっと」
3. 出典URLが自動で入るので、「📥 クリップボードから貼り付け」で本文を入れる
4. 「送信」

### 手動(iPhoneなど)
アプリを開いて本文を貼り付け、必要なら出典URLも貼って「送信」。

## セットアップ

1. スマホのChromeでこのページを開く
2. メニュー →「ホーム画面に追加」でインストール
   - **共有メニューに出るのはインストール後だけ**です
3. 開いて「サインイン」→ Googleアカウントを選び、Driveへのアクセスを許可

## 設定

`config.js` の `GOOGLE_CLIENT_ID` に、GCPで発行したWebアプリケーション型クライアントIDを入れます。
**PC側の拡張機能と同じクライアントIDを使うこと**(同一クライアントID = Driveから見て同一アプリなので、
最小スコープの `drive.file` のままファイルを共有できます)。

クライアントIDは公開前提の値で秘密情報ではありません。クライアントシークレットは使いません。

## 技術メモ

- 素のHTML/JS。ビルドツールなし
- アクセストークンは**メモリ保持のみ**。localStorage/IndexedDBには書きません
- 送信に失敗したものはIndexedDBのキューに積み、次回起動時に自動再送します
- Service Workerのキャッシュは最小限(オフラインでフォームが開く程度)
